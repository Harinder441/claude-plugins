# My Explainers

A Claude Code plugin containing explainer skills that teach platform concepts by reading official documentation.

## Skills

| Skill | Description |
|-------|-------------|
| [shopify-explainer](skills/shopify-explainer) | Explains Shopify concepts by reading official Shopify documentation (shopify.dev, help.shopify.com) |

## Installation

```bash
claude plugins add /path/to/my-explainers
```
